Telltale

開源 Flutter OBD2 車輛遙測與診斷
Open-source Flutter OBD2 telemetry and diagnostics

繁體中文 English

繁體中文

Telltale 透過 ELM327 相容轉接器讀取即時車輛資料與 OBD2 故障資訊，並在資料不完整或互相衝突時明確顯示不確定。

一個看起來合理的錯數字，比沒有數字更糟。

連線方式

  • Bluetooth Classic / RFCOMM（僅 Android）
  • Bluetooth LE / GATT
  • Wi-Fi / TCP
  • 內建 Demo ECU

Android 是目前主要完成實體裝置、UI 與 BLE 測試馬具驗證的平台；iOS 與 macOS 只有編譯閘門，不能視為已完成實機或實車驗證。

從 GitHub Releases 下載 APK 查看原始碼

安裝前注意：GitHub APK 使用社群簽章，無法更新 Google Play 版，Play 版也無法直接更新它。兩者互換必須先解除安裝，會刪除 App 本機資料；請先匯出需要保留的診斷紀錄並記下設定。

目前的驗證邊界

已驗證：Samsung 實體手機到 Mac 的真實 BLE/GATT 無線路徑，搭配模擬 ELM327，已完成掃描、連線、UART 寫入與通知。

尚未驗證：CAR25 或其他購入轉接器、其韌體與 profile、ECU/CAN 匯流排，以及真車。

請只在車輛停妥時操作，或交由乘客操作。清除 DTC 前先保存診斷證據。App 不會主動上傳資料；你匯出的紀錄可能含 VIN、裝置與轉接器識別資訊。

English

Telltale reads live vehicle data and OBD2 faults through an ELM327-compatible adapter, while making incomplete or conflicting evidence visibly uncertain.

A plausible wrong number is worse than no number.

Connections

  • Bluetooth Classic / RFCOMM (Android only)
  • Bluetooth LE / GATT
  • Wi-Fi / TCP
  • Built-in Demo ECU

Android is the primary physically tested platform for device, UI, and BLE-rig paths. iOS and macOS currently have compile gates only, not equivalent physical-device or vehicle verification.

Download APK from GitHub Releases View source

Before installing: GitHub APKs use a community signing key. They cannot update, or be updated by, the Google Play build. Switching requires uninstalling Telltale, which removes local app data; export diagnostic records and note any settings you need first.

Current verification boundary

Verified: a real Samsung-to-Mac BLE/GATT radio path using a simulated ELM327, including discovery, connection, UART writes, and notifications.

Not yet verified: CAR25 or another purchased adapter, its firmware and profile, an ECU/CAN bus, or a real vehicle.

Use Telltale only while parked or as a passenger. Save diagnostic evidence before clearing DTCs. The app proactively uploads nothing; exported records may contain VIN, device, and adapter identifiers.
